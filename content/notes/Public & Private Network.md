## Private Network and Public Network

- LAN MAN aur WAN ye private network ke type hai
- waise hi internet ye public network ka type hai
- LAN, MAN aur WAN hum hamare gharo me humare do branch office ke bichme humare private communication ke liye hum LAN, MAN, WAN deploy karte hai
- Jaise LAN, MAN, WAN ye private network ka type hai waise internet ye public network ka type hai
- Internet ye kisi ek ke baap ka nahi hai ye sabke baap ka hai 
- Internet does not belong to any single entity
- Internet is interconnection of multiple service providers
- Internet par hum humare services dete hai aur dusro se unki services lete hai 
- quki internet pure globe ko bhi connect karne ke kaam aata hai
- isliye Internet ko aksar largest WAN bhi kaha jaata hai
