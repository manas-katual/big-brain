Every Starting letter of a word in Java if it is in capital letters it is a predefined class in java there are around more than 10000 predefined classes.

example code
```java
class Test{
	public static void main(String []args){
		System.out.("Hello");
	}
}
```
Here in this code there are 3 classes one is which I had declared called `Test` and other 2 are `String` an `System`
