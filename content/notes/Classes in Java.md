Every Starting letter of a word in Java if it is in capital letters it is a predefined class in java there are around more than ==10000 predefined classes==.

example code
```java
class Nitin{
	public static void main(String []args){
		System.out.("Hello");
	}
}
```
Here in this code there are 3 classes one which I had declared called `Nitin` which is ==userdefined== and other 2 are `String` and `System` which are ==predefined==
