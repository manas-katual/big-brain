## Router

- Router is an intelligent device so after a receiving a packet it will check its ip address and after that it will check whether it is in the routing table and then only it will accept the packet. Switch switches within the network. Router routes between the network




- Every upper layer device will do lower layer function also, router refers routing table to take forwarding decision ( L3 function ), it will also modify the frame and change MAC addresses ( L2 function ) and restore signal level before forwarding the frame ( L1 function ).
- Multiple ports of router can have same MAC address or multiple MAC addresses.
