to make multiple blocks for a variable/memory is called arrays

```c
void main()
{
    int a[5], i;
    printf("Enter any 5 subjects marks: ");
    for(i=0;i<5;i++)
    {
        scanf("%d", &a[i]);
    }
    for(i=0;i<5;i++)
    {
        printf("%d ", a[i]);
    }
}
```
